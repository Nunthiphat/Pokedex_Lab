# 🧩 Pokémon Info Website

A simple website that displays information about Pokémon using data fetched from the [PokéAPI](https://pokeapi.co/).  
Built with **HTML** and **JavaScript**, the website allows users to view Pokémon and view their stats, types, and images.

## 🔧 Technologies Used
- HTML
- CSS (basic styling)
- JavaScript (for API calls and DOM manipulation)
- PokéAPI

## 🚀 Features
- Display Pokémon name, type, image, and base stats
- Real-time data fetching from PokéAPI
